# Pi SME Project Presentation Website

This is a static, GitHub Pages-ready presentation.

## Presentation controls
- Right Arrow / Space: next slide
- Left Arrow: previous slide
- F: full screen
- N: show/hide speaker notes
- Home: first slide

## Publish with GitHub Pages
1. Create a repository such as `pi-sme-project-presentation`.
2. Upload all files in this folder, including `assets/`.
3. Commit to the `main` branch.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**.
6. Choose `main` and `/(root)`.
7. Save.

## Important security rule
Do NOT upload:
- `.env`
- API tokens
- passwords
- SECRET_KEY
- private credentials

The website uses only project details and screenshots already shared in this conversation.
